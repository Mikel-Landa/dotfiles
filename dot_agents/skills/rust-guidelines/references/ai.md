# AI Guidelines

> Source: https://microsoft.github.io/rust-guidelines/agents/all.txt

Open only the rule needed for the current Rust task.

- [`M-DESIGN-FOR-AI`](rules/m-design-for-ai.md) — Design with AI use in mind — maximum utility from agents working in your codebase.
- [`M-NO-META-DESIGN-DOCUMENTATION`](rules/m-no-meta-design-documentation.md) — Avoid meta design documentation — docs focused on what is relevant to users.
- [`M-RUST-SHAPED`](rules/m-rust-shaped.md) — Rust code solves Rust problems — idiomatic code.
- [`M-SINGLE-ITEM-PATH`](rules/m-single-item-path.md) — Items are only visible through one path — a single, clutter-free path to each type.
- [`M-TAUTOLOGICAL-TESTS`](rules/m-tautological-tests.md) — Tests do not assert ground truth — tests that add value, not noise.
