# Documentation

> Source: https://microsoft.github.io/rust-guidelines/agents/all.txt

Open only the rule needed for the current Rust task.

- [`M-CANONICAL-DOCS`](rules/m-canonical-docs.md) — Documentation has canonical sections — established Rust documentation practices.
- [`M-DOC-INLINE`](rules/m-doc-inline.md) — Mark `pub use` items with `#[doc(inline)]` — re-exported items that fit in with their siblings.
- [`M-FIRST-DOC-SENTENCE`](rules/m-first-doc-sentence.md) — First sentence is one line; approx. 15 words — easily skimmable API docs.
- [`M-MODULE-DOCS`](rules/m-module-docs.md) — Has comprehensive module documentation — easy API docs navigation.
